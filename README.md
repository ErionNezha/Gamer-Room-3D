# 🎮 Gamer-Room-3D

Dhomë gamer-i 3D e ndërtuar tërësisht me CSS (pa WebGL): kliko posterin për të ndezur dritat, ekranin e videos e muzikën. Të gjitha asset-et tani lokale.

## 🚀 Si ta hapësh

Hap `index.html`, kliko **Live Demo**, pastaj kliko posterin në mur për efektet.

## 📁 Struktura

```
Gamer-Room-3D/
├── index.html
├── demo/  (dhoma 3D + assets/)
├── original/  (origjinali)
```
